# Getting Started with NotzUp
NotzUp is in development. Signed official installers have not been released. When verified software is ready it will appear at https://github.com/vpicciuolo/oyyo-notzup/releases with checksums, signatures and release notes.

Capture audio, screen, video and typed notes (subject to native platform permissions), import documents or authorized saved provider content, organize a private library and generate AI Context Packs. Free local use; 50 MB registered cloud text/Markdown/transcript sync when shipped. This public repo is the official source for user guides and release downloads, not the full proprietary source.

## v4 account and local engine requirements
Account registration is required for licensed runtimes. Free permits up to 26 captured minutes/session, 10 confirmed bookings/month, and two registered installations. Transcription, summarization and AI run on your own device, with no cloud model fallback; 50 MB content storage is optional and not automatic upload. Plus $5.99/month and Pro $9.99/month are planned for verified release, not live checkout.
