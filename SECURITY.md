# Private security reporting
NotzUp is pre-release software. Avoid publishing vulnerabilities, secrets or customer materials in public GitHub issues. Use private GitHub vulnerability reporting when available, or contact HRN via https://hrn.ae. No unsupported security certification is claimed. Official signed release packages, account isolation, encryption controls, secure OAuth, transparent capture indicators, deletion and privacy policies are release gates.
