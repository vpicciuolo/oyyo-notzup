# Android, iPhone and iPad
Target platform support, not released. Android will require user-visible permissions such as MediaProjection for screen capture; iOS requires AVFoundation/ReplayKit and App Store-approved permissions. Audio from other applications is restricted on mobile and cannot be guaranteed. Authorized connected service history is a different capability from native capture.
