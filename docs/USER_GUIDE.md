# Complete OYYO NotzUP User Guide

This guide follows the product from first launch to capture, local analysis, review, export, encrypted backup and account services. Controls can vary by platform because Android, iOS, Windows, macOS, Linux and browsers expose different permissions.

## 1. First launch and local core engine

1. Install NotzUP from an official Store or verified release package.
2. Open the app and follow the full-screen guided tour.
3. Sign in when you want account, entitlement, cloud storage, backup, sharing, calendar or connector features.
4. Approve only the permissions required by the capture you select.
5. Keep the app open while the verified local core engine downloads and checks its signature automatically.
6. Open **Settings > Local intelligence** to review download or verification status.

Expected result: the app reports that its local speech engine is ready. If the download is interrupted, reconnect and use the Settings verification control.

Privacy note: the downloaded engine processes supported customer content on the device. It is not a cloud transcription fallback.

## 2. Capture audio

1. Open **Capture** and choose **Audio**.
2. Check microphone permission and participant consent.
3. Start recording and keep the visible system/app indicator available.
4. Pause or resume when supported.
5. Stop and save safely.
6. Open the saved item in **Library**.

Expected result: the local original is saved and can be played, transcribed and organized.

Troubleshooting: if the waveform or timer does not move, check Android or desktop microphone permission, Bluetooth routing and whether another app holds the microphone.

## 3. Record a screen or meeting

1. Choose **Screen recording** or the supported meeting-capture entry.
2. Review the Android or desktop system permission sheet.
3. Select the eligible screen, app window or display.
4. Enable microphone voice only when needed and authorized.
5. Start capture, then stop from NotzUP, its floating control or the system notification.

Expected result: a local video file with its available audio tracks. Protected video, cellular calls and third-party private audio may be blocked by the operating system.

## 4. Take a photo, scan or screenshot

1. Choose **Photo**, **Scan** or **Screenshot**.
2. Fill the frame with the useful subject and avoid glare.
3. Capture and confirm the image.
4. Wait for local OCR and visual analysis.
5. Review **Visual analysis** and **Visible text** separately.

Expected result: the original image, extracted text and grounded visual observations stay connected in one file workspace.

## 5. Import a supported file

1. Choose **Import file**.
2. Select an audio, video, image, document, text or other supported media file.
3. Wait for the local copy and metadata to finish saving.
4. For speech media, choose transcription when it is not started automatically.
5. For an image, document or video, run visual/text analysis when needed.

Expected result: the source appears once in Library with the relevant workspace tabs. Codec and document support depends on the platform.

## 6. Play the original

1. Open the item and select **Overview**.
2. Use **Play audio** or **Play video**.
3. Tap the player to show seek, pause and resume controls.
4. Return to the workspace without deleting or re-importing the source.

If audio works but video is black, verify that the source video codec is supported by Android and that the file is complete. Re-importing cannot repair a damaged source.

## 7. Transcribe speech locally

1. Confirm that the local core engine is ready.
2. Open an audio or video item.
3. Choose **Transcribe** or **Transcribe again**.
4. Keep the app available while the local job runs.
5. Review and edit names, punctuation and uncommon terms.

Expected result: an editable transcript stored with the source. Mixed-language accuracy depends on the recording and installed model.

## 8. Understand images and silent video

1. Open an image, scan, screenshot or video.
2. Select **Visual analysis**.
3. For video, NotzUP samples frames across the timeline, so analysis works even without audio.
4. Review scene labels, detected object classes, general labels, face counts and visible-text references.
5. Treat possible names or brands found in visible text as hints, not verified identities.
6. Choose **Search detected objects and names** only when you want to send those search terms to a browser search provider.

Expected result: a detailed, editable visual description that stays separate from OCR text and audio transcription.

## 9. Work with a file workspace

Use the horizontal tabs to move between **Overview**, **Transcript**, **Visual analysis**, **Visible text**, and **Summary and actions**. Scroll the tabs horizontally when the screen is narrow.

For any populated section:

1. Long-press to select and copy a portion.
2. Choose **Edit section** to revise the complete result.
3. Choose **Copy section** or **Share section** for only that tab.
4. Choose **Export section** and select Markdown, Excel, text or PDF.
5. Use the top export card for a full branded PDF, complete ZIP, Copy all or Share package.

## 10. Create a summary and action items

1. Review the source transcript or extracted text first.
2. Open **Summary and actions**.
3. Choose **Create** or **Refresh summary and actions**.
4. Check every decision, date, owner and action against the source.
5. Edit incorrect or incomplete passages before export or sharing.

Generated results are drafts. NotzUP keeps them tied to the source so the user can verify them.

## 11. Translate offline

1. Install the required supported language pack when offered.
2. Open a text-bearing result.
3. Choose **Translate offline**.
4. Select the target language.
5. Review names, numbers and domain terminology.

Expected result: translated text generated on the device without uploading the captured source to a cloud AI model.

## 12. Export and share

- **Markdown:** best for notes, repositories and knowledge tools.
- **Excel:** best for structured tables and inventory results.
- **TXT:** a portable plain-text copy.
- **PDF:** a branded, printable document with header, logo, website and company footer.
- **ZIP package:** the original plus the selected generated results.

Share only the minimum section needed. Review the Android share destination before sending, because another app's privacy rules apply after export.

## 13. Scan a barcode inventory

Use the dedicated [Mobile Barcode and QR Inventory guide](MOBILE_BARCODE_INVENTORY.md). The feature is mobile-only, currently Android, and requires Pro or Organization.

## 14. Back up and restore encrypted results

Use the [Encrypted Backup and Cloud Storage guide](ENCRYPTED_BACKUP_AND_STORAGE.md). Configure two-factor authentication, protect the recovery key, select the correct storage space, and test a restore before relying on the backup.

## 15. Manage notifications

1. Open the bell icon.
2. Open an item to reach its safe destination.
3. Mark individual notifications read, or use **Read all**.
4. Use **Delete all** only after confirming that the notification history is no longer needed.
5. Open Settings to review native notification permission and preferences.

In-app and native push delivery depend on account configuration, device permission and the event's enabled delivery channels.

## 16. Manage storage, devices and sessions

1. Open the web account or mobile Settings.
2. Review personal and Organization storage separately.
3. Check quota, stored files and current storage add-on.
4. Review enrolled devices and remove only an installation you recognize.
5. Review active account sessions separately from enrolled device slots.
6. Download required backups before deleting cloud files.

## 17. Use calendar and bookings

1. Open **Calendar** or **Bookings**.
2. Create or review an event type and your personal public booking page.
3. Check time zone, availability, duration, buffers, minimum notice and guest questions.
4. Preview and share your personal booking link.
5. Let the guest choose an available time in their own time zone.
6. Review confirmation, rescheduling or cancellation from the authenticated booking area.
7. Use the `.ics` file or configured calendar connector where supported.

Booking limits and provider synchronization depend on the plan and connector status. A booking duration does not change recording limits.

See [Personal Booking Pages and Meeting Links](PUBLIC_BOOKING_PAGES.md) for the complete setup, privacy and troubleshooting guide.

## 18. Connect a provider

1. Open **Connectors**.
2. Choose the provider.
3. Read the provider's own permission screen.
4. Approve only the scopes needed.
5. Return to NotzUP and verify the connection status.
6. Disconnect it from NotzUP and the provider security page when no longer needed.

Signing in with Google or Microsoft does not automatically grant calendar or file access.

## 19. Report a problem

1. Open support from the help icon, or use the app's shake-to-report control when enabled.
2. Review the diagnostic information before sharing it.
3. Remove private names or content from screenshots and notes.
4. Describe what you tapped, what you expected and what happened.
5. Include app version, Android or desktop version and device model.

Never place recordings, recovery keys, passwords or private account tokens in a public GitHub issue.
