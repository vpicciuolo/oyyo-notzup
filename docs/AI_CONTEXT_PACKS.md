# AI-ready exports
NotzUp will produce portable structured Markdown, subtitles, plain text, JSON and ZIP packs: SOURCE.md, TRANSCRIPT.md, ACTIONS.md, DECISIONS.md, QUESTIONS.md, RISKS.md, AI_CONTEXT.md, AGENTS.md and checksummed MANIFEST.json. Users review the material before sharing it with ChatGPT, Claude, Gemini, OYYO or any other provider. External API processing is distinct from user-controlled handoff into a consumer chat.
