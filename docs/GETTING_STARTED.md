# Getting Started with NotzUp
NotzUp is in development. Signed official installers have not been released. When verified software is ready it will appear at https://github.com/vpicciuolo/oyyo-notzup/releases with checksums, signatures and release notes.

Capture audio, screen, video and typed notes (subject to native platform permissions), import documents or authorized saved provider content, organize a private library and generate AI Context Packs. Free local use; 10 MB registered cloud text/Markdown/transcript sync when shipped. This public repo is the official source for user guides and release downloads, not the full proprietary source.
